# reports/ ディレクトリについて

- `reports/latest.md` は、Claude Code が各作業(コード変更、設定変更、調査など)の後に生成・更新するローカルの作業レポートです。
- 主な用途は、ChatGPT など他のツール・他のセッションへのレビュー引き継ぎです。
- `reports/latest.md` 自体は **Git 管理対象にしません**(`.gitignore` で除外済み)。前回の内容は上書きされ、常に最新の作業状態のみを反映します。
- `reports/latest.md` には、実デバイスのシリアル番号など、ユーザー固有の識別情報を生値で記録しないでください。必要な場合は `<redacted>` または `Device A` / `Device B` のように匿名化した表現を使ってください。
